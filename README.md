NetProbe v5
NetProbe v5 is an offline‑capable network scanner and security assessment toolkit designed for pentesters, blue‑team analysts, and network engineers. It combines host discovery, port scanning, OS detection, vulnerability analysis, credential spraying, threat scoring, and reporting into one unified tool. Every core feature works without API keys, making it ideal for internal networks, restricted environments, and air‑gapped systems.

Features
Works 100% Offline
NetProbe v5 includes a full suite of scanning and enumeration modules that require no cloud access:

ARP, ICMP, and IPv6 host discovery

Port scanning with banner grabbing

OS fingerprinting

SSL/TLS inspection

Local vulnerability scanner (built‑in DB)

Compliance checks

Packet sniffer

SNMP enumeration

NetBIOS/SMB enumeration

HTTP directory brute‑forcing

DNS zone‑transfer testing

Credential spraying (multi‑protocol)

CPE mapping (local regex engine)

Wi‑Fi scanning

Honeypot detection

Traceroute

Threat scoring

Historical tracking (SQLite)

HTML, PDF, and Markdown reporting

If Nmap is installed, NetProbe automatically integrates with it and parses XML output into structured results.

Why NetProbe v5
NetProbe v5 is built for environments where reliability, privacy, and autonomy matter. It avoids cloud dependencies, stores all data locally, and provides deep visibility into network assets without exposing anything externally. Whether you’re mapping a new network, hunting misconfigurations, or performing a full security audit, NetProbe v5 gives you the tools to do it efficiently and safely.

Usage
Run NetProbe from the command line or through its GUI interface. Results are saved automatically and can be exported as HTML, PDF, or Markdown reports.
